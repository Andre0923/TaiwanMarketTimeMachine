
- log、test、程式碼、文件等檔案 MUST 放在對應目錄，
```
logs/              ← 日誌檔案
tests/             ← 測試檔案
src/               ← 程式碼
docs/              ← 專案文件
specs/             ← 規格文件
docs/user-stories  ← User Story 文件
```
